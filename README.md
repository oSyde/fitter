# fitter

A dark, mobile-first workout companion built with Next.js App Router, TypeScript, Tailwind CSS, Radix Dialog, Framer Motion, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The weekly split is saved in this browser with `localStorage`.

## Included

- Editable Monday–Sunday split with a 51-movement searchable exercise library
- Set, rep, target load, and personal note fields per exercise
- Local persistence and automatic selection of the current weekday
- Focus mode with elapsed timer, set logging, rest countdown, exercise navigation, and session recap
- Quick workout option for rest days
